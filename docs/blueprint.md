# **App Name**: ExpenseWise

## Core Features:

- Add Expense: Allow users to add expenses with title, amount, category, date, and payment method.
- Expense Display: Automatically show total expenses and list individual expenses with options to edit and delete.
- Category-wise Summary: Display a summary of expenses categorized by type (Food, Travel, etc.).
- Data Storage: Store data locally using local storage.
- Filtering Options: Enable users to filter expenses by category and date.
- Spending Patterns Graph: Generate simple charts to visualize spending patterns.
- Dark Mode Toggle: Allow users to switch between light and dark mode.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to evoke trust and financial responsibility.
- Background color: Light gray (#F0F4F7), very desaturated, for a clean interface.
- Accent color: Soft green (#A5D6A7), analogous to blue, to indicate gains or savings.
- Body and headline font: 'PT Sans', a humanist sans-serif for readability and a modern feel.
- Use minimalistic, clear icons to represent expense categories and actions.
- Employ a dashboard-style layout with a focus on mobile responsiveness.
- Add subtle transitions and animations for a smooth user experience when interacting with expenses.
